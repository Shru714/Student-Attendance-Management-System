5. DATABASE SETUP
================================================================================

DATABASE NAME: attendance_system

TABLES:
-------
1. users - Admin, teacher, student login credentials
2. classes - Class information
3. teachers - Teacher profiles
4. students - Student profiles
5. attendance - Attendance records
6. leaves - Leave management records

SETUP OPTIONS:
--------------
Option 1: Using START_APP.bat (Recommended)
   - Run START_APP.bat
   - Select option 3: Import Database with Demo Data
   - Follow prompts

Option 2: Manual Import
   - Open MySQL command line
   - Run: mysql -u root -p < server/database/schema_with_data.sql
   - Enter password when prompted

Option 3: Empty Schema
   - Run START_APP.bat
   - Select option 2: Import Database (Empty Schema)
   - Manually add data through admin panel

CONFIGURATION:
--------------
Database: attendance_system
Server Port: 3001
MySQL User: root
MySQL Password: (set in server/.env)

Environment file location: server/.env
Contains:
- DB_HOST=localhost
- DB_USER=root
- DB_PASSWORD=your_password
- DB_NAME=attendance_system
- PORT=3001
- JWT_SECRET=your_secret_key

6. TROUBLESHOOTING
================================================================================

ISSUE: Login not working
SOLUTION:
   - Check credentials are exact (case-sensitive)
   - Clear browser cache (Ctrl+Shift+Delete)
   - Hard refresh (Ctrl+F5)
   - Check browser console for errors (F12)

ISSUE: Database connection failed
SOLUTION:
   - Check MySQL is running
   - Verify credentials in server/.env
   - Run START_APP.bat → Option 4: Check Database Connection
   - Ensure database exists: SHOW DATABASES;

ISSUE: Frontend not loading
SOLUTION:
   - Clear browser cache
   - Check browser console for errors
   - Ensure all files are in correct directories
   - Try opening in incognito mode

ISSUE: Attendance not saving
SOLUTION:
   - Check browser console for errors
   - Verify localStorage is enabled
   - Try clearing localStorage and reloading demo data
   - Ensure date and time are selected

ISSUE: Leave button not visible
SOLUTION:
   - Clear browser cache (Ctrl+Shift+Delete)
   - Hard refresh (Ctrl+F5)
   - Check that you're logged in as Admin
   - Verify script version is v=26

ISSUE: Class filter not working in reports
SOLUTION:
   - Clear browser cache completely
   - Reload page (Ctrl+F5)
   - Check browser console for debug messages
   - Verify attendance records have correct classId

ISSUE: Teacher ID showing N/A
SOLUTION:
   - Clear all data
   - Load demo data again
   - New teachers will auto-generate IDs (TCH001, TCH002...)

ISSUE: Students not loading in attendance
SOLUTION:
   - Ensure demo data is loaded
   - Select a class from dropdown
   - Check that students are assigned to that class
   - Refresh page if needed

ADDITIONAL INFORMATION
================================================================================

LEAVE MANAGEMENT WORKFLOW
-------------------------
1. Admin clicks "Leave" button for teacher/student
2. Modal opens with leave form and history
3. Admin fills in start date, end date, and reason
4. Submits leave request (status: pending)
5. Admin can approve or reject from leave history
6. Status updates with color coding:
   - 🟢 Green = Approved
   - 🔴 Red = Rejected
   - 🟠 Orange = Pending

ATTENDANCE MARKING WORKFLOW
---------------------------
1. Teacher logs in
2. Selects class from dropdown
3. Students auto-load for that class
4. Teacher marks Present/Absent for each student
5. Selects date and time
6. Clicks "Save Attendance"
7. System checks for duplicates
8. Saves attendance records
9. Shows success notification

REPORT GENERATION WORKFLOW
--------------------------
1. Admin goes to Attendance Reports
2. Selects report type (Student or Date)
3. Applies filters (student, date range, class)
4. Views statistics and records
5. Exports to CSV or PDF if needed
6. Can save report to database

DEMO DATA LOADING
-----------------
1. Login as Admin
2. Look for "Load Demo Data" button on dashboard
3. Click button
4. Confirmation message shows data loaded
5. Page reloads with demo data
6. All features now testable with sample data

CLEARING DATA
-------------
Method 1: Browser DevTools
   - Press F12
   - Go to Application/Storage tab
   - Click Local Storage
   - Right-click and select Clear
   - Refresh page

Method 2: Console
   - Press F12
   - Go to Console tab
   - Type: localStorage.clear()
   - Press Enter
   - Refresh page
